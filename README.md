# Conecta con Ubidots

Página interactiva del foro **(ABRetos) ¿Como se realiza la conexión con UBIDOT IoT?**
Universidad Privada Franz Tamayo · Ingeniería de Sistemas · La Paz - Bolivia · 2026

Incluye: maleta de requisitos, rutas HTTP / MQTT / TCP-UDP con recomendador, itinerario de 6 paradas, generador de código (curl, mosquitto, netcat, ESP32 HTTP y MQTT), simulador con retos para el docente y casos que fallan, y quiz.

Sitio estático: `index.html`, `style.css`, `app.js`. El simulador funciona en el navegador y no se conecta a Ubidots real; el token de la página es de ejemplo.
