1 · Antes de salir

Prepara tu maleta

Conectar un dispositivo con Ubidots necesita pocas cosas. Márcalas cuando las tengas claras; la barra te dice qué tan lista está tu maleta.

Maleta lista: 0 de 6

  • ✓
    Una cuenta de UbidotsEl nivel STEM es gratuito y está pensado para aprender. Ahí vivirán tus dispositivos, variables y tableros.
  • ✓
    Tu tokenLa llave de tu cuenta. Se copia desde API Credentials. Trátalo como una contraseña y no lo subas a GitHub.
  • ✓
    Un nombre para el dispositivoSu label: minúsculas, sin espacios, como esp32-aula. Va en la URL, el tópico o el mensaje.
  • ✓
    Una variable por magnitudTemperatura, humedad, ventilador… Cada una se guarda por separado y lleva su propio label.
  • ✓
    Un dispositivo con redPor ejemplo, una placa ESP32 con Wi-Fi, o un módem celular. Sin red no hay viaje.
  • ✓
    Una herramienta para probarcurl, mosquitto o netcat desde tu computadora te dejan comprobar la ruta antes de programar la placa.
2 · Elige tu ruta

Cuatro formas de llegar a Ubidots

Todas apuntan al mismo destino, industrial.api.ubidots.com. Cambia el puerto, la forma de enviar el token y el tipo de respuesta.

HTTP · REST

Una petición a la vez

Puerto
80 (443 con TLS)
Ruta

Token
Cabecera X-Auth-Token
Cuerpo
JSON: {"temperatura": 24.5}
Respuesta
Un código HTTP que puedes leer
Ideal para: enviar cada tanto y probar rápido con curl.

Una conexión que se queda abierta

Puerto
1883 (8883 con TLS)
Usuario
Tu token
Contraseña
Vacía (o el mismo token)
Tópico
/v1.6/devices/<label>
Cuerpo
El mismo JSON de HTTP
Ideal para: enviar seguido y recibir órdenes al instante.
TCP · UDP

Una línea de texto y listo

Puerto
9012 (9812 con TLS)
Token
Dentro del mensaje
Mensaje
app/1.0|POST|TOKEN|dev=>var:val|end
Límite
5 conexiones por segundo desde una misma IP
Diferencia
TCP confirma la entrega; UDP no
Ideal para: módems celulares y equipos con poca memoria.

      Seis preguntas rápidas

      En resumen

      Lo que te llevas del viaje

      Todo empieza en el tokenSe copia de API Credentials, identifica tu cuenta y se trata como una contraseña.
      El destino es el mismoindustrial.api.ubidots.com; cambian puerto y formato según la ruta.
      HTTP es la puerta fácilUn POST con JSON y una cabecera. Responde con un código que puedes leer.
      MQTT es ida y vueltaUsuario = token. Publicas en /v1.6/devices/<label> y te suscribes para recibir órdenes.
      TCP y UDP son ligerosUn mensaje con barras verticales al puerto 9012. UDP no confirma nada.
      El dispositivo nace soloSi el label no existe, Ubidots lo crea con el primer dato. Cuida mayúsculas y espacios.
